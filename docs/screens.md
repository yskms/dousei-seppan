# 同棲折半：画面設計メモ

画面の一覧、画面の移り方、各画面に出す内容をまとめる。仕様の正本は [企画メモ](plan.md)、データとAPIは [バックエンド設計メモ](backend-design.md)。この文書は、それらを画面に落としたもの。

見た目（色・余白・部品）の細かい指定はここでは決めない。決めているのは次だけ。

- 白・ライト基調。ダークモードにも対応する
- アクセントカラーは、アイコンのピンク（`#FC75A4` 付近）
- 金額は大きく、精算の向き（誰が誰に）は矢印と名前で、ひと目で分かるようにする

---

## 1. 全体の構成

```
起動
 ├─ 未ログイン → ログイン画面
 │                └─（招待URLから来たとき）ログイン後に参加確認へ
 └─ ログイン済み
      ├─ グループが無い → グループ作成
      └─ グループがある → メイン（タブ）

メイン（下のタブ）
 ├─ 月      … 選んだ月の集計と支出の一覧。支出の追加ボタン、締めボタン
 ├─ 履歴    … 締めた月の一覧と、その結果
 └─ 設定    … カテゴリと負担割合、固定費、メンバーと招待、グループ、アカウント
```

- タブは3つに絞る。支出の登録は、「月」タブの右下の追加ボタン（FAB）から行う
- 複数のグループに入っている人は、画面上部のグループ名をタップして切り替える。グループが1つの人には、切り替えの操作を見せない
- 最後に開いたグループを覚えておき、次の起動ではそのグループを開く
- データは、画面を開いたときとタブに戻ったときに取り直す。引っ張って更新（pull to refresh）もできる。プッシュ通知やリアルタイム更新はMVPに入れない

### ログインなしのお試し（MVPの後）

ログインは必須とする。メインの画面ができた後に、ログイン画面へ「ログインせずにサンプルを見る」を足す。

- サンプルのグループ（例：家賃は7:3、外食は月1万円まで自分）を端末内に持ち、支出を足したり消したりすると、負担額と送金がその場で変わる
- 計算は、サーバーと同じTypeScriptの関数を端末で動かす。データは保存しない
- 締め・招待・固定費・設定は、「ログインすると使えます」と案内してログイン画面に戻す
- この画面は、ストアのスクリーンショットにも使える

## 2. ログイン・はじめての設定

### ログイン画面

- アプリ名、ひとことの説明（「ふたりの生活費を、決めた割合で月ごとに精算」など）
- 「Appleでサインイン」「Googleでログイン」の両方を、両OSで出す。iOSではAppleを上、AndroidではGoogleを上にする
- 招待URLから来たときは、上部に「ふたりで使うには、データ保護のためログインが必要です」と出す。ログイン後は、招待情報を持ったまま参加確認に進む
- プライバシーポリシーと利用規約へのリンク

### グループ作成

ログイン後、グループが1つも無いときに出す。入力は最小限にして、すぐ使い始められるようにする。

- グループ名（初期値：「ふたりの生活費」。後から変えられる）
- 自分の表示名（このグループの中での名前。Apple / Googleの名前は使わない）
- 通貨（初期値：日本円。支出を1件登録した後は変えられない）

作ると、次の初期カテゴリを作る（自分100%）。相手が参加した月に、均等にリセットされる（企画メモ8章）。

- 家賃、食費、日用品、光熱費、外食、通信費、その他

作った後は「月」タブを開き、「相手を招待する」のカードを目立たせる（後述）。

### 参加確認（招待URLを開いたとき）

ダイアログで出す。開いただけでは参加しない。

- グループ名、招待した人の表示名
- 自分の表示名の入力（初期値なし。必須）
- 「参加する」「キャンセル」
- 期限切れ・使用済み・取り消し済みの招待は、「この招待URLは使えません。招待した人に、新しいURLを送ってもらってください」と出す
- すでにそのグループに参加中なら、そのグループを開くだけにする

## 3. 「月」タブ（ホーム）

アプリを開いて最初に見る画面。選んだ月の集計と、その月に登録した支出を出す。

### 表示する月

- 初期表示は、**支出を登録できる月のうち、カレンダー上の今月に最も近い月**。今月が未締めなら今月、早めに締めていれば翌月
- 上部の「◀ 2026年6月 ▶」で、締めていない月の間を移動できる（例：6月3日に、まだ締めていない5月を見る）
- 締めた月は「履歴」タブで見る。「◀」で締めた月まで戻ったときは、履歴の画面を開く

### 画面の上から順に

1. **お知らせ**（あるときだけ。複数あれば重ねて出す）
   - 前の月の送金が未処理：「5月分の精算が残っています 相手 → 自分 17,000円」。タップで5月の締め結果を開く
   - 前の月が未締め（今月を見ているとき）：「5月はまだ締めていません」。タップで5月に移動
   - メンバーが増減した：「メンバーが変わったため、負担割合を均等に戻しました。見直してください」。タップでカテゴリの一覧へ
   - 固定費が止まった：「家賃の固定費が止まっています。支払う人を選び直してください」。タップで固定費の編集へ
   - 1人だけのグループ：「相手を招待する」のカード
2. **先月からの繰越**（あるときだけ）
   - 「先月分 相手 → 自分 17,000円」。この月の集計には含めないことが分かる書き方にする
3. **いまの精算見込み**（いちばん大きく出す）
   - 2人のとき：「相手 → 自分 12,300円」の1行
   - 3人以上のとき：送金の一覧（締めたときと同じ組み合わせ方で出す）
   - 差額が0のとき：「いまのところ精算はありません」
   - 下に小さく「この月を締めると確定します」
4. **メンバーごとの内訳**（折りたたみ。初期は閉じる）
   - メンバーごとの支払額・負担額・差額
   - カテゴリごとの合計と、各メンバーの負担額（上限額つきのカテゴリは「月1万円まで自分」を添える）
5. **支出の一覧**
   - 日付の新しい順。1行に、カテゴリ、内容（無ければカテゴリ名）、支払った人、金額
   - 「この支出だけ負担を変える」を付けた支出には、印を付ける
   - 固定費から作られた支出には、固定費の印を付ける
   - タップで編集を開く
6. **「この月を締める」ボタン**（一覧の下）

右下に、支出の追加ボタン（FAB）を常に出す。

### 締めるボタンを押せないとき

ボタンは出したまま押せなくし、理由を添える。

- まだ始まっていない月：ボタン自体を出さない
- 前の月が未締め：「先に5月を締めてください」
- 前の月の送金が未処理：「先に5月分の精算を済ませてください」

## 4. 支出の登録・編集

下から出るシート（モーダル）で開く。登録の手順を少なくするため、上から順に、よく変える項目を並べる。

1. **金額**：開いたらすぐ数字キーボードを出す
2. **カテゴリ**：横に並んだチップから選ぶ。初期値は前回選んだカテゴリ
3. **支払った人**：メンバーの切り替え（セグメント）。初期値は自分
4. **日付**：初期値は今日。自由に選べる（登録する月と関係なく選べる）
5. **内容**：任意。1行
6. **登録する月**：選べる月が2つ以上あるときだけ出す（例：「5月分 / 6月分」）
   - 初期値は、日付の月が登録できる月ならその月、できなければ、登録できる月のうち今月に最も近い月
   - 早めに締めた月の日付を選んだときは、「5月は締めたため、6月分として登録します」と添える
7. **この支出だけ負担を変える**：スイッチ。オンにすると、次を出す
   - 方法：割合で分ける / 均等に分ける / 金額を指定する / 1人が全額負担
   - 割合・金額は、メンバーごとに入力する。合計が合わないときは、差を出して保存できなくする
   - 各メンバーの負担額のプレビュー

下に「保存」。編集のときは「削除」も出す（確認ダイアログあり）。

- 締めた月の支出は、同じシートを読み取り専用で開く。保存・削除は出さない
- 削除されたユーザー・脱退が確定したメンバーは、新しく登録する支出の支払者・負担の対象に選べない（既存の支出には名前のまま出す）
- 保存したときに他のメンバーの更新とぶつかった場合は、サーバーが1回だけやり直す（バックエンド設計メモ8章）。それでも失敗したときは「他のメンバーが更新しました。もう一度保存してください」と出し、入力内容は消さない
- 保存しようとした月が、その間に締められていたときは、「6月は締められました。7月分として登録しますか？」と聞く

## 5. 締めと精算

### 締めの確認

「この月を締める」を押すと、確認のシートを出す。

- 確定する送金の一覧（「相手 → 自分 17,000円」）
- 「締めた後は、この月の支出を追加・変更・削除できません」
- 月の途中で締めるときは、「まだ月の途中です。この月の残りの支出は、7月分として登録します」を目立たせる
- 脱退を選んでいるメンバーがいるときは、「Aさんの脱退は、この月を締めると確定します」
- 「締める」「キャンセル」

締めたら、その月の締め結果の画面を開く。他のメンバーが先に締めていた・支出を変えていたときは、「他のメンバーが更新しました」と出して、月の画面を読み直す（締めはやり直さない）。

### 締め結果

締めた月の結果。「履歴」タブからも開く。

1. **送金**（いちばん上。月が処理済みになるまで目立たせる）
   - 送金ごとに、向き・金額・状態（未処理 / 精算済み / 繰越済み）
   - 未処理の送金には「精算した」「来月に繰り越す」のボタン。どちらも確認ダイアログを出し、確定後は戻せないことを書く
   - 繰越できない送金（脱退するメンバー・削除されたユーザーが関わる）は、「繰り越す」を出さず、「脱退するメンバーとの精算は繰り越せません」と添える
   - 精算済み・繰越済みは、操作した日を添える
2. **メンバーごとの支払額・負担額・差額**
3. **カテゴリごとの合計と負担額**（締めた時点の割合・上限額を添える）
4. **支出の一覧**（読み取り専用）

すべての送金が処理済みになったら、「5月分は処理済みです」と出し、月の画面へ戻る導線を出す。

---

## 6. 「履歴」タブ

締めた月の一覧。新しい順。

- 1行に、月、支出の合計、送金の要約（「相手 → 自分 17,000円」）、状態（未処理あり / 処理済み）
- タップで締め結果を開く
- 見られるのは、自分が参加（または復帰）した月以降だけ
- Premiumの導入後は、Freeは直近3ヶ月だけ見られる。それより古い月は、一覧に鍵の印を出してPremiumに案内する（未処理の月は常に見られる）。MVPには入れない

## 7. 「設定」タブ

```
設定
 ├─ このグループ
 │   ├─ カテゴリと負担割合
 │   ├─ 固定費
 │   ├─ メンバーと招待
 │   └─ グループの設定（グループ名、通貨、自分の表示名）
 ├─ アカウント
 │   ├─ ログアウト
 │   └─ アカウントを削除
 └─ このアプリについて（プライバシーポリシー、利用規約、お問い合わせ、ライセンス、バージョン）
```

### カテゴリと負担割合

**一覧**

- 上部に、対象の月（「6月の負担割合」）。締めていない月の間で切り替えられる。初期値は「月」タブで見ている月
- カテゴリごとに、名前と割合（「家賃 7:3」）。上限額つきなら「外食 月1万円まで自分、超えた分 0:10」
- 「カテゴリを追加」。並べ替えは長押しのドラッグ
- 変更は、選んだ月とそれ以降の月に反映される（締めた月は変わらない）ことを、一覧の下に書く

**割合の表示**

- 2人のとき、10%単位で割り切れる割合は「7:3」、それ以外は「65% : 35%」と出す
- 3人以上のときは、%で並べる（「40% / 30% / 30%」）
- 均等にリセットした割合（3人の33.34% / 33.33% / 33.33%など）は「均等」と出す

**カテゴリの編集**

- 名前
- 負担割合
  - 2人のとき：スライダーと、よく使う割合のボタン（5:5、6:4、7:3、8:2、10:0）。1%単位
  - 3人以上のとき：メンバーごとの%入力と「均等にする」。合計が100%でないときは、差を出して保存できなくする
  - 0.01%単位の入力は見せない（DBは0.01%単位で持つ。均等のリセットのときだけ使われる）
- 上限額つきにする（スイッチ）
  - 上限まで負担する人、上限額（月あたり）
  - オンにしたとき、超えた分の割合の初期値は、上限まで負担する人を0%、残りを均等にする
  - 説明の例を、入力した値でその場に出す（「月の合計が8,000円なら、自分が8,000円。15,000円なら、自分が10,000円、相手が5,000円」）
- 対象の月（「6月から」）
- 「このカテゴリを使わない」（アーカイブ）。過去の支出は残る。新しい支出では選べなくなる

### 固定費

**一覧**

- 名前（内容）、金額、毎月の日、支払う人、カテゴリ
- 止まっている固定費は、上にまとめて理由を出す（「支払う人が脱退しました」「メンバーが変わったため、負担の見直しが必要です」）

**編集**

- 金額、内容、カテゴリ、支払う人、毎月の日（1〜31日。29〜31日は「その日がない月は月末日」と添える）
- この固定費だけ負担を変える（支出の登録と同じ入力）
- 開始する月。変更は、まだ作っていない月の分から反映することを書く
- 「止める」「再開する」「削除」

### メンバーと招待

- メンバーの一覧と状態
  - 参加中
  - 脱退予定（「6月で脱退。締めるか7月1日に確定」）
  - 脱退済み（名前は残す）
  - 削除されたユーザー
- **招待する**：招待URLを作り、OSの共有シートを開く。送る文面の例：「同棲折半で生活費を一緒に記録しよう。このURLから参加できます（3日間有効）」
- 未使用の招待の一覧（自分が作ったもの）。期限と「取り消す」
- **このグループから脱退する**
  - 確認ダイアログ：「6月で脱退します。6月を締めるか、7月1日に確定します。確定するまでは取り消せます」
  - 自分が支払う人の固定費があれば、「家賃の固定費は、支払う人を選び直す必要があります」と添える
  - 最後の1人のときは、「このグループのデータはすべて削除され、元に戻せません」と出し、ボタンも「グループを削除して脱退」にする
  - 脱退予定の間は、ここが「脱退を取り消す」になる

### グループの設定

- グループ名
- 自分の表示名（このグループでの名前）
- 通貨（支出が1件もないときだけ変えられる）

### アカウントを削除

- 説明：すべてのグループからすぐに脱退すること、名前は「削除されたユーザー」になり、支出・精算の記録はグループに残ること、自分が最後の1人のグループは削除されること、元に戻せないこと
- 精算が残っている送金があれば、「削除すると、この精算は繰り越せなくなります」と添える
- 再認証（Apple / Googleでもう一度ログイン）してから削除する
